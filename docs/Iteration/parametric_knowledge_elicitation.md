# 参数知识激发、上下文污染，与冷启动 Harness

> 定位：检索控制面的缺失分支，以及「对话如何查询模型权重」的机制讨论。  
> 性质：思辨与设计约束，不是实现施工单。  
> 相关：`docs/Iteration/retrieve_gate/retrieve_policy_controller_design.md`  
> 日期：2026-09-03

---

## 0. 命题

外部记忆（LanceDB、用户史、本轮助手结论）解决的是：这个人、这个项目、上一次失败。

参数知识（模型权重）解决的是：文明里已经压进网络的解法空间、机制、反例与眼界。

冷启动时第一套是空的。用户要的不是「没有记忆的聊天」，也不是对空库做一次向量检索。用户要的是：用人的对话当寻址键，把权重里已经有的东西尽可能挖出来，给人启发或方案。

同时必须承认另一面：对话一旦形成轨道，就会污染这次挖掘。相关即约束。所谓极致调用内部信息，首先是防污染，其次才是「写更长的回答」。

---

## 1. 两套记忆，不要合成一套

| 来源 | 冷启动 | 谁该被检索 |
|---|---|---|
| 外部：用户史、项目记忆、权威业务库 | 空，查了是噪声 | 应跳过 |
| 内部：权重里的世界知识、框架、鉴别诊断 | 满的 | 应被刻意激发 |

非科研、非私有事实的任务上，第二套往往已经超过「再搜一遍网上常识」。人要做的不是给模型补知识，而是提供足够尖的检索键：目标、约束、口味、当前卡点。

因此：

- Agent 需要记忆系统。
- 冷启动不需要 *external* memory。
- 需要控制面承认：参数记忆也是一等公民。
- `SKIP` 外部检索之后，若只丢空 `memory_context` 再聊天，那不是激发，只是没检索。

EverOS 一类系统的冲动是：尽快抽取、落盘、进化。此处采取相反策略：

```text
冷启动：少写记忆，多逼问模型
确认之后：才把用户的选择与事实写入外部记忆
```

未确认的畅想若当成「用户的长期记忆」，以后 Gate 会检索到助手自己的口吻。熵只会下降。

## 2. 当前 SKIP 为什么不够

Retrieve Policy Controller 里，SKIP 的下一跳常常是：

```text
Continue Agent Reasoning
```

实现上对应：空上下文，把球扔回基座模型。

这会失败，因为：

1. 没有规定推理该用哪一套知识（世界先验 vs 用户史）。
2. 长对话本身已经占据 working memory，权重寻址被窗口劫持。
3. 「显得有帮助」的对齐目标会把输出锁在当前用语能拼出的邻域里。

Gate 需要的不是更漂亮的布尔，而是至少三条动作：

```text
Need Estimator
   ├── SKIP_EXTERNAL + ELICIT     冷启动 / 无用户史 / 通用方案
   ├── FAST / STANDARD / DEEP     外部记忆
   └── HYBRID                     用户约束去裁剪参数知识
```

有了目标、偏好、失败经验之后，外部检索开始工作；参数知识仍在，但被用户记忆裁剪和否决，不能再当「对大多数人成立」的最佳实践直接倒出来。

## 3. 上下文污染的机制（不是比喻）

Transformer 没有「先查权重、再看对话」的独立总线。Prompt 里每个 token 都在改下一 token 的分布。

后果：

1. **相关即约束。** 人类交际按关联原则压缩；RLHF 强化「接着对方的框架说」。项目讲得越清楚，续写越像项目文档，越不像能从医学、军事决策、科学史、教育测量里借火的东西。
2. **知识冲突时，当代对话模型偏向上下文。** Prompt 陈述与权重事实打架时，对齐过的模型更容易跟 prompt。有记忆、有长对话，会系统性压过参数知识。
3. **一致性是探索的敌人。** 一旦某个词被用作答案（control plane、elicitation、SKIP），后续生成会把问题拟合进这些词，而不是重新搜索权重。
4. **助手自己的上一句是最烈的污染。** 检索助手历史，等于检索上一轮的口吻。

空库时的失败模式因此不是「没搜外部库」，而是：

```text
窗口（working memory）劫持权重（parametric long-term）的寻址
```

「对话激发内部知识」只对了一半。激发靠的是**新的、高信息的用户句**，以及**刻意丢掉的旧助手句**。把整段聊天当 query，等于用污染源当索引。

## 4. 权重里到底有什么，内部检索的上限

参数不是百科数据库。更接近：在互联网级文本上压出来的、高度纠缠的预测机。

里面有：

- 大量可复述的中位答案（人人写过的框架）。
- 相当数量的机制、反例、学科切口；触发条件很窄，问法要像那门课的考题，不像产品闲聊。
- 严重的方向性：A→B 会、B→A 不会（reversal curse 一类现象）。
- 尾部知识极不稳定：越是「极致方案」，越可能是流畅的假专家。

因此「极致调用内部信息」有硬上限：挖到的是**当前问法能激活的训练分布盆地**，不是全知 `SELECT * FROM weights`。

Harness 的工作不是假装能扫全参数，而是：

```text
故意制造多种寻址键，把模型从当前盆地拽到别的盆地
```

一次顺承的长回答做不到这一点。那只是把同一个盆地说得更满。真要挖权重，就要付多次失忆调用、多种人格、一次合成的成本。产品若不肯付，就不要写「极致调用内部知识」。

校准也很差：口头自信不等于知道。内部检索的质量，看它能否主动拿出反例；拿不出反例，就是流畅的假检索。

## 5. 激发协议：能落地的，不是神秘的权重搜索

权重不能 `top_k`。能做的是协议。

### 5.1 失忆生成，再对齐

对同一用户句，至少两条前向：

- **世界机：** 几乎无历史。只保留用户原话 + 用户白纸黑字声明过的事实（不是助手总结）。
- **记忆机：** 带着外部记忆与用户原文，不读世界机的草稿。

两边不一致时，默认不用带记忆的那条去统一叙事，而是把差异摊开。今天常见 agent 是反面：先读记忆再说话，第一原则从未出场。

关键约束：

> 激发不应发生在已经读过长对话、尤其是助手历史的那一次前向里。  
> 带上下文的 Harness 可以做路由与计划；知识倾倒必须在剥掉助手历史的另一次调用里做。  
> 否则 elicitation_plan 只是被污染的模型在给自己布置作业，作业题还是那些词。

「SKIP 外部 + 返回 elicitation_plan」若仍在同一窗口里执行倾倒，只是 API 字段，不是防污染。

### 5.2 先扩搜索空间，再评价

禁止第一轮出「推荐方案」。强制先从互不相干的来源各取一条，来源必须异质到无法共用当前项目黑话。然后才允许合并或淘汰。没有这一步，启发全是中位互联网的架构口吻。

可借用的异质来源（示例，不是清单）：

- 可靠性工程（故障模式、可逆性）
- 临床决策（诊断 → 鉴别 → 再治疗）
- 军事参谋课（目标、敌情、己力、时间）
- 游戏数值（反馈循环）
- 证据法（什么不可采信）
- 教学（如何引入新概念而不灌输）

### 5.3 多人格并行，禁止互相读稿

同一问题给互斥的系统约束，例如：只许谈失败模式；只许谈最小可逆实验；只许谈十年尺度；只许谈无团队时的穷人做法。温度拉开，多样本，再聚类。这是在用采样近似「换一条电路」。单次低温度长文是最差的内部检索。

### 5.4 先问检索键，再倒知识

冷启动第一轮可以不是长方案，而是少数几个能改变解法空间体积的问题。信息增益最大的问题，不是寒暄。问错了，后面一万字都在错误盆地里精装修。

### 5.5 自对抗与「不求帮助」

方案出来后必须有一轮：哪条是训练语料里的陈词、哪条依赖未核实前提、新手与老手会怎样改。RLHF 会压掉尖锐、失礼、像在否定用户路线的内容；极致方案经常长在那里。法定一轮「不求帮助、只求反驳」，产出必须能否定当前主线，否则算失败。

### 5.6 三色分开

输出必须能分开：

```text
参数知识     训练分布里的世界
用户事实     用户说过、可核对
助手臆想     本轮流畅但未证实
```

冷启动时把后两种的音量拧到接近零。禁止在没有用户记忆时使用「根据你一贯的风格」这种假记忆句式。

### 5.7 用户点头的才入库

可持久化的只有：

- 用户的选择
- 用户提供的事实
- 用户明确 pin 的句子

助手的宏大框架一律当**易失 briefing**，默认过期。对话激发出的长文，不是记忆。

## 6. 更极端、可以和「聊天 + RAG」不像的形态

### 6.1 双推理机

一台永远不读用户记忆，只读本轮问题与世界。  
一台只读记忆和用户原文，不读另一台的草稿。  
第三步才是冲突解决：私事听记忆，通法听世界；或交给用户点选。

先 retrieve 再生成，是把两台叠成一台，污染是结构注定的。

### 6.2 知识编译器，不是聊天

用户任务进来，主输出不是回复，是一份**限时有效的地图**：可能的学科、可能的失败、需要的实验、不该相信模型的部分。聊天只是浏览这张地图的 UI。地图不进长期记忆，除非用户撕下一角 pin 住。

### 6.3 模型当非线性词典，人当查询语言

专家知识引出（如关键决策法）问的是「你当时靠什么信号判断」，不是「请给最佳实践」。对 LLM，等价物是逼它做**鉴别诊断**：什么情况下方案 A 是错的。内部检索的质量看反例，不看流畅。

### 6.4 为多样本计费

一条回复里堆更满的段落不是更极致，是同一盆地的更高密度。产品必须承认：失忆调用 × 人格 × 合成，才是「检索内部」的计量单位。

## 7. 冷启动之后：HYBRID

外部记忆一旦存在，不要关闭参数知识。

HYBRID 的意思：

```text
记忆  →  这个人、这个项目的约束与否决
权重  →  领域里已经存在的解法空间
```

要防两头：

- 空库还硬查外部，污染为噪声。
- 有了用户史还在用「对大多数人成立」覆盖「这个人已经选过的路」。

权威业务事实（例如确定性计算出来的指标、交易、病历）不应塞进「激发用」的向量库，也不应与参数倾倒混成一种 context。事实走事实口；启发走失忆世界机；私事走记忆机。

---

## 8. 对人侧：若要从模型压出更多

不要在同一条 meta 轨道上说「再极致一点」。那通常仍是同一盆地的更高密度。

换键，例如：

- 只丢任务句，禁止沿用已有模块名与已有结论。
- 指定两个不相干学科，只许从那里回答。
- 要求列出十个会让当前路线作废的事实。
- 要求一次完全失忆的回答，与带历史的回答并列，不许提前和解。

那才是人侧的内部检索协议。

---

## 9. 设计上明确不做什么

- 不把「激发内部知识」理解成对权重做真正的向量检索，或再挂一个「知识模型」假装可搜。
- 不把冷启动长文自动写成外部记忆。
- 不在已读助手历史的同一次前向里自称完成了极致内部检索。
- 不以「更全的 Memory OS、更多抽取流水线」作为彻底性。彻底性在于：检索是策略，污染可隔离，参数与用户事实分色，决策可回放。
- 不以单次长回答当作极致。极致是过程：多样本、失忆、对抗、再合成。

## 10. 可检验的标志

一套 Harness 若自称能激发参数知识，至少应能在 trace 里看到：

```text
是否发生了剥除助手历史的独立前向
是否发生了异质来源展开（在评价之前）
是否发生了法定反驳且反驳能否定主线
写入记忆的条目是否仅含用户选择 / 用户事实 / pin
输出是否分色：参数 / 用户事实 / 臆想
冷启动时外部检索是否确实为 SKIP，且没有假装「根据你的历史」
```

缺一项，就还是「空 context 的聊天」或「被长对话污染的续写」。

---

## 11. 一句话

记忆系统的长期目标若是控制面，则冷启动不是记忆的失败模式，而是控制面的第一种非平凡状态：外部静音，参数被多键寻址，助手的话不准立刻变成记忆。上下文不是资料，是会改写寻址的场；要挖权重，先把场拆开。

## 12. 哲学上的对应与书单

记性太好会生病。真正的知往往不是从仓库里取出来的，是被一次打断激活的。下面这些切法对着同一问题；书为这些切法服务，不是哲学史课表。

**遗忘是能力，不是故障。** 尼采：人必须能不历史地活；历史感过强，行动会瘫痪。Gate 若有哲学身份，就是有时限的遗忘：不是把库删掉，是这一刻不允许过去占领现在。纪念碑式历史（伟大模板）、古物式历史（什么都收藏）、批判式历史（为了活而审判过去）——外部记忆很容易变成前两种；控制面要的是第三种。

**外置记忆是药，也是毒。** 柏拉图《斐德罗》：文字是 pharmakon，帮你记得，也让灵魂不再自己记。对话能按对方改口；写下来的稿会假装自己还活着。LanceDB、聊天记录、上一轮助手的「结论」都是文字的后代。冷启动挖权重，是还没写成药的那次回忆（anamnesis）。一写进记忆，启发就变成教条。

**我们知道的，多于能说的。** 波兰尼：默会知识在判断与习惯里，不在手册里。权重是一种畸形的默会——被压进参数，没有身体，却同样不能按目录打开。内部检索是引出，不是 SQL。

**先有形式，才有经验。** 没有范畴，感官只是杂多。用户第一句话不是在空地上盖房子，是在已经存在的结构上显影。应先让权重里的世界结构工作，再让这个人的记忆来限制它。先倒用户史再想，是经验主义的庸俗版，也是上下文污染。

**图画囚禁了我们。** 维特根斯坦：一幅图画把我们俘虏了。长对话就是那幅画。失忆前向、异质学科、法定反驳是在砸瓶，不是在瓶壁上写满注释。

**注意是一种伦理。** 韦伊：注意是最稀有、最纯粹的慷慨。不是多检索，是把心灵空出来。有记忆而不住在记忆里。私事听从这个人，通法听从世界，两者都不许冒充对方。

**集体记忆不是个人记忆。** 哈布瓦赫、利科：我们以为在记自己，其实在记群体给的框架。权重是集体记忆的压缩；用户库才是传记。冷启动用集体记忆启发个人是正当的；把集体记忆写进个人档案是身份盗窃。遗忘可以是伤害，也可以是前进的条件。Gate 要设计的是第二种。

**「忘」可以比「记」更高。** 《庄子》：得鱼忘筌，坐忘，心斋。王阳明：理不在外面格物格到。第一轮不要格外部记忆，先致那一大块已经在模型里的常理，再让这个人的选择落到「这个」。

**技术就是外置的记忆。** 斯蒂格勒：人靠工具记事（tertiary retention），药与毒同体。Agent 记忆系统会改人能想什么。拒绝什么都抽取，是拒绝让第三持留吞掉此刻的印象与意识里的回想。控制面是药学剂量，不是更大的仓库。

### 12.1 先读、会直接改你怎么想 Gate 的

1. **尼采《历史对于人生的利与不利》**（收入《不合时宜的沉思》）  
   最短、最狠。记太多如何使人不能行动。读完再看 SKIP，会不一样。

2. **柏拉图《斐德罗》**（尤其文字 / 记忆那一段）  
   外置记忆的药性。对话为什么被认为比写下来的稿更接近思想。

3. **保罗·利科《记忆，历史，遗忘》**  
   厚，可当工具书。真正要的是：记忆的责任、遗忘的正当、叙事如何冒充过去。不必从头到尾。

4. **迈克尔·波兰尼《个人知识》**（或较短的《隐性维度》）  
   为什么「在里面」的知识拉不出来，引出意味着什么。这是 elicitation 的哲学，不是 RAG 的哲学。

5. **维特根斯坦《哲学研究》**（不必整本：前言、语言游戏、苍蝇瓶、看见-看作）  
   上下文如何变成牢笼。会识别人和模型怎样一起把图画画圆。

6. **彼得·阿多《作为生活方式的哲学》**  
   把问、忘、复盘当成练习（askesis），而不是理论。Harness 若不想做成 API 宗教，需要这种自我理解。

7. **贝尔纳·斯蒂格勒《技术与时间》第一卷**（难；可先读较清楚的访谈或南京课程一类导引）  
   外置化记忆、产业时间、注意力被技术改写。若要把记忆做成「比仓库更彻底」，对手是这个传统，不是又一个向量库。

8. **柏格森《材料与记忆》**  
   习惯记忆 vs 形象记忆。procedural / episodic 的分裂，他用身体与纯记忆说了一遍。难，但问题是同一个。

### 12.2 「忘 / 住」

9. **《庄子》**（先读内篇《齐物论》《大宗师》《应帝王》；郭象注可后放）  
   坐忘、心斋、浑沌。冷启动的「空」若有正面形象，与其来自 blank slate，不如来自这里。

10. **《金刚经》**（短，反复读）  
    「应无所住而生其心」。有记忆而不住，几乎是 HYBRID 能有的最干净的一句话。

### 12.3 「注意 / 看」而不是「存 / 取」

11. **西蒙娜·韦伊《重负与神恩》**（笔记体，可跳着读与注意相关的条目）

12. **奥古斯丁《忏悔录》第十卷**  
    记忆的宫殿；在自己里面找一个装不下的库。

### 12.4 刻意后放

黑格尔大逻辑、海德格尔《存在与时间》全文——不是不重要，是太容易变成新的黑话，再关进另一幅图画。先把遗忘、药、默会、图画、外置这五件事读透。

同一周不要读两本「建体系」的。尼采或《斐德罗》配《庄子》一段，比同时开利科和斯蒂格勒更接近被打断，而不是又被一套上下文吸进去。
